# 习惯是怎样形成的？｜Huberman Lab 视觉化动画

基于本知识库的 [双语笔记](../../Clippings/The%20Science%20of%20Making%20%26%20Breaking%20Habits%20%20Huberman%20Lab%20Essentials.md)，将主要概念重写为原创简体中文科普视觉分镜。

## 使用方式

- 在浏览器打开 `index.html`：自动播放，←/→ 切换，空格暂停。浏览器可直接查看各张矢量图。
- `frames/01.svg` 至 `frames/10.svg`：10 张 16:9（1280 × 720）独立可缩放矢量分镜，易于继续编辑。
- 本次对话另提供 40 秒、带原创轻音乐的 MP4 文件。仓库版采用不需构建环境的 HTML/CSS/JS 动画，方便在本地或 GitHub Pages 播放。

## 分镜结构

## 科学表达注意事项

节目中“21 天计划”是一种自我实验的练习建议，而非每个人、每种习惯都适用的固定期限。不同的人和习惯所需时间跨度很大。“边缘系统摩擦”是 Huberman 自己创造的方便表达的词，不是正式临床诊断术语。图中的方法是对节目建议的可视化，并不代表每一项都已获得同等强度的独立验证。
