# How Habits Take Shape — English Edition

A 10-scene English adaptation of the [bilingual Huberman Lab clipping](../../../Clippings/The%20Science%20of%20Making%20%26%20Breaking%20Habits%20%20Huberman%20Lab%20Essentials.md). The ten SVG images are **original editable vector artwork**.

## Open and edit

Open [index.html](index.html) in a browser. It auto-plays each scene and supports pause, back/forward, arrow keys, and Space. No build tools or external libraries are needed. Every frame can be opened or edited separately with an SVG editor.

- `frames/01.svg`–`frames/10.svg`: fully English 16:9 illustrations
- `narration_en.txt`: optional English voiceover script
- `narration_en.srt`: matching English subtitle timings
- The English-text MP4 (40 sec), PNG exports, and contact sheet are attached in the accompanying ChatGPT conversation. The MP4 contains original ambient music **but no voice narration**.

## Scene order

Neuroplasticity → variable formation time → activation energy → linchpin habits → mental rehearsal → task bracketing → daily rhythms → 21-day experiment → replacement action → flexible habits.

## Scientific caveats

21 days is a suggested *practice structure* in the episode, **not** a universal habit-formation timeframe. The source reports a study with wide time variation. “Limbic friction” is Huberman's informal explanatory phrase, not a standardized diagnostic term. These visuals are illustrations, not demonstrations of guaranteed effects.
