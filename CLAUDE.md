# Knowledge vault

Read and follow the root `AGENTS.md` for this vault's search and note-maintenance rules. Read `wiki/meta/agent-search.md` for the implementation details and current coverage.

After a batch of changes to indexed Markdown, maintain relevant navigation pages and run QMD `update`, incremental `embed`, and `status` with the vault-local configuration. Check command exits and pending embeddings before reporting completion. This is agent-driven maintenance; no background watcher is installed.
