# 项目｜4位 ALU：从组合模块到数字系统

> [!abstract] 项目目标
> 不再停留在单个 MUX、半加器或全加器的题目，而是把已会的基础模块组合起来，完成**要求 → 结构 → 实现 → 验证 → 时间行为**的工程闭环。
> 所属：[[lessons/数字逻辑与系统/课程阶段#阶段 3｜组合模块|阶段 3 · 组合模块]]；延伸至 [[lessons/数字逻辑与系统/课程阶段#阶段 4｜时序与存储|阶段 4 · 时序与存储]]、[[lessons/数字逻辑与系统/课程阶段#阶段 6｜数据通路与控制|阶段 6 · 数据通路与控制]]。

本文件**只维护可复用的项目规格、学习层次和各层验收标准**。哪天实际做了什么、遇到何种错误、是否通过验收，记录在对应的日记里；不要在此维护第二套动态完成状态。

## 统一项目规格

设计一个组合逻辑 4 位 ALU，输入两个4位二进制数和2位操作码；输出4位运算结果及状态标志。

| 信号 | 位宽 | 含义 |
| --- | --- | --- |
| A、B | 各4位 | 操作数（位模式）；算术溢出判断时按4位二补码解释 |
| Op | 2位 | 选择运算 |
| Y | 4位 | 结果，算术运算仅保留低4位 |
| Z | 1位 | Y=0000 时为1 |
| C | 1位 | 加法：最高位进位；减法：1表示无借位，0表示借位 |
| V | 1位 | 加减法的4位**有符号溢出** |

| Op | Y 的功能 | 标志约定 |
| --- | --- | --- |
| 00 | A + B | 依据4位加法得到 C、V |
| 01 | A - B | 依据4位减法得到 C（无借位标志）、V |
| 10 | A AND B（逐位与） | C=0、V=0 |
| 11 | A XOR B（逐位异或） | C=0、V=0 |

所有操作均计算 Z=(Y==0000)；四位加/减结果按模16截断。**C 与 V 是两种不同的判断，不能混为一谈**：C 描述无符号进位/借位约定，V 描述二补码有符号结果是否溢出。初版不增加寄存器，输入变化后输出经传播延迟稳定。

## 任务层次与验收

### 第 1 层｜功能规格与模块架构（优先学习）

**核心问题**：对于给定的4种运算，哪些功能是公共的？哪些模块可复用？控制信号如何让正确的数据到达输出？

**做什么**：
1. 自己定义并核对 A、B、Op、Y、Z、C、V 的位宽与含义，画出 ALU 外部接口。
2. 把加法/减法通路、AND/XOR 通路、结果选择、标志位生成划分为若干模块；判断哪些模块可以共用。
3. 在**模块级框图**上画出数据通路和控制通路，标清 Op 影响哪些路径，连线携带的是1位还是4位。
4. 口头或文字追踪两种不同操作码从输入到输出的路径，并说明 C、V 为什么不能只靠 Y 的最高位判断。

**交付物**：一张带信号方向与位宽的模块框图 + 一张简短的接口/操作码表 + 两段信号路径解释。

**通过标准**：
- 4种 Op 都有明确的数据来源和被选中的输出路径，功能规格无歧义。
- 可以解释加减法为何有望复用算术通路；不用在本层完成逐门实现。
- Z/C/V 来源在架构上有位置，标志的语义彼此不混淆。
- 面对别人指出的遗漏模块或位宽错误，可以修改并解释原因。

**停止点**：结构解释清楚即可收工。本层**不要求**绘制全加器内部细节、不要求编写 Verilog、不要求完成1024组测试，也不要求估算最长延时。

### 第 2 层｜结构落地与资源复用

**核心问题**：如何把框图变成确定的电路，而不是复制两套加减法器？

**做什么**：把4个全加器串联成行波进位；推导减法所需的 B 位变换和初始进位；使用 MUX 完成结果选路；实现 Z/C/V。可以选用 Logisim、Multisim、Verilog 或完整的门/模块级连接图。

**交付物**：可复现的实现或完整连接图，并注明设计假设。

**通过标准**：加/减法确实共享所设计的算术路径；进位方向正确；接口与第1层规格一致；能够解释位宽截断及两类溢出/进位标志的来源。

### 第 3 层｜验证与定位错误

**核心问题**：怎样证明电路不仅在一两个例子上正确？

**做什么**：设计覆盖边界的案例（至少16组）；有仿真条件时穷举 16×16×4=1024 种组合，与独立期望值比较；修改一个模块或操作码，检查能否定位失配。

**建议边界案例**：0111+0001、1111+0001、0000-0001、1000-0001、0000 AND 1111、1010 XOR 1010；还需覆盖 Z/C/V 的不同取值。

**交付物**：测试表或测试程序、测试结果、一个典型错误定位过程（没有真实错误可主动注入一个故障）。

**通过标准**：功能、进位、溢出和零标志都能经案例核对；发现不符时可区分“算术计算错、选路错、标志错”。

### 第 4 层｜传播延迟、关键路径和优化

**核心问题**：逻辑正确的结果是否立即可用？结构怎样影响速度？

**做什么**：找出行波进位的最坏信号传播路径；考虑 Op 切换与多路信号同时变化时的暂态输出；比较行波进位与超前进位的性能/成本（定性优先，数值需明确门延迟模型）。

**交付物**：一张传播路径与波形说明 + 一份可解释的结构对比。

**通过标准**：能说出组合逻辑稳定需要时间、为什么可能出现毛刺、为什么进位链会限制速度；不把理想逻辑值与瞬态物理电压混为一谈。

### 第 5 层｜时序化延伸（之后再选择）

给 ALU 接寄存器和时钟，明确何时采样输入、何时结果有效；可添加简单 FSM 控制连续操作，讨论时钟周期、建立/保持时间。该层属于通往时序与系统设计的桥梁，**不是前四层同时完成的要求**。

## 项目推进方式

- **一次只聚焦一层**，通过该层的证据再选择下一层；不把全部层次塞进次日计划。
- 已经会的门电路/MUX/加法器基本题不设为例行必做，仅当出现相关错误时回退。
- 每次做完把作品链接、出错位置、独立性、是否达到本层标准和一个下次启动点记在当天日记，并让日期记录反向链接本页。
