# 项目｜从布尔逻辑走到4位ALU

> [!abstract] 目标与难度
> **4位ALU是本项目的终点，不是第一天的起点。** 刚从布尔代数进入组合逻辑，可以先用1位的功能选择建立结构感，再逐渐加入加法、进位、多位运算。允许回看知识卡片，但尽量先回答问题再查解释。

归属：[[lessons/数字逻辑与系统/课程阶段#阶段 3｜组合模块|阶段3 · 组合模块]]；延伸到时序与数据通路。**实际学习状态只记在当天日记**，本页只保存可重复使用的问题与验收标准。

## 0｜先修知识：只需理解这些

| 名词 | 一句话理解 | 你需要能做什么 |
| --- | --- | --- |
| 布尔函数 | 把输入的0/1映射成输出的0/1 | 根据条件列真值表 |
| 与 / 异或 | 与：都为1才为1；异或：不同才为1 | 判断任意A、B的输出 |
| MUX | 根据选择信号从几条数据路径中取一路 | 区分数据输入、选择端、输出 |
| 位宽 | 1位只表示0或1；4位有4个二进制位置 | 区分单线与多位总线 |
| 半/全加器 | 半加器接A、B；全加器还接低位进位 | 区分本位和与进位 |
| ALU | Arithmetic Logic Unit，按操作码选择算术/逻辑功能的模块 | 解释“运算”和“选路”是两件事 |

**先不用掌握**：补码减法、有符号溢出、超前进位、Verilog、时序约束；到对应层次再补。遇到陌生术语先问“它接收什么、输出什么、为什么系统需要它”，而不是背定义。

## 1｜一位、两种运算：把函数变成模块（当前入口）

**规格**：输入A、B、Op各1位；输出Y为1位。Op=0时 Y=A AND B；Op=1时 Y=A XOR B。

**连续思考（按顺序作答，先不看现成图）**

1. 当A=B=1时，两种运算的结果一样吗？如果结果不同，电路如何知道该选哪一个？
2. A、B和Op都属于输入，但它们的**职责**相同吗？谁是数据，谁是在决定使用哪种规则？
3. 先假设与门和异或门都已经给出了结果：现在你只差一个什么模块，才能按Op选择输出？
4. 这个选择模块该有几条数据输入、几位选择信号、几条输出？请自己画方框和箭头。
5. 不需要给出门级内部结构：只考虑A、B、Op共有多少种组合？怎样证明每一组输出正确？
6. 若明天改成“Op=0选择异或，Op=1选择与”，哪些连接需要改，哪些运算模块可以不变？

**验收**：独立画出“两个运算模块+选择模块”的结构，标注信号方向；列出A、B、Op的8行真值表，并说明改操作码后改变的是哪一部分。此层只要求一个输出Y。

## 2｜为什么加法还要多一条输出？

**补充知识**：两个1位数相加可能产生两位结果（如1+1=10₂），因此加法模块通常分开输出本位和S、进位C。

**连续思考**

1. 第一层只有一个Y。若新运算是1位相加，A=B=1时只用一个输出位会丢失什么？
2. 半加器给出了S和C：当它成为多个二进制位中的“中间一位”时，还缺少哪一个输入？
3. 能否将“与/异或”保留为原有模块，把加法作为新增候选路径？操作码至少需要几位？
4. 不进行加法时，进位输出应如何定义，才能避免接口含糊？

**验收**：画出新增加法功能后的模块框图，解释S、进位、运算选择端各自的作用。无需设计四级进位链。

## 3｜从1位变成4位：模块怎样拼装？

**补充知识**：每一位的加法都可能收到上一低位传来的进位；逐级传递称为**行波进位**。4位信号由4根二进制线组成。

**连续思考**

1. 如果四位的“按位与”可以把一位电路复制四份，那么加法是否也能完全各算各的？哪种信息必须跨位传递？
2. 第0位产生的进位应该送到哪里？继续传递四次时，哪一级的结果可能最后稳定？
3. 假设已有4位加法、按位与、按位异或三条路径，应该在哪个位置选择最终的4位结果？
4. 你画出的选择线是1位还是多位？数据通路又是几位？逐条标注后有无接错宽度的风险？

**验收**：画4位结构框图，能追踪最低位进位到最高位的路径，并区分控制信号与4位数据总线。

## 4｜拓展为完整4位ALU：减法与标志

**目标规格（到本层才要求）**

| 输入/输出 | 解释 |
| --- | --- |
| A[3:0]、B[3:0] | 两个4位操作数 |
| Op[1:0] | 00加、01减、10按位与、11按位异或 |
| Y[3:0] | 四位结果；加减只保留低4位 |
| Z | Y为0000时置1 |
| C | 加法时表示最高位进位；减法时1表示无借位 |
| V | 4位二补码的有符号加减溢出；逻辑运算置0 |

**补充知识**：补码减法把A−B转化为A+（B逐位取反）+1；**C（进位/无借位）和V（有符号溢出）并非同一件事**。逻辑运算约定C=V=0。

**连续思考**

1. 为什么A−B能借用加法器？B经过怎样的变换、最低位的初始进位是多少？
2. 如果加法与减法想复用同一条算术通路，应该由哪一个控制信号决定“反相B/初始进位”？
3. 假设结果Y=0000，可以不用知道输入就判断哪个标志？
4. 同样的4位结果，在无符号和二补码有符号解释下，会不会对应不同的溢出判断？如何设计反例？
5. 如果所有运算都正常，如何判断最终应该选哪一路Y？C和V又应属于哪种操作？

**验收**：完成完整模块图（包括加减复用、MUX、Z/C/V），并以边界例子解释进位与溢出的区别。此层可以查阅补码和溢出知识，不要求一次想出所有细节。

## 5｜证明正确，再研究时间（可后续选学）

**验证**：先自己挑选覆盖普通、零结果、进位/借位、溢出的测试案例；如果已经会写测试，再穷举A、B、Op全部16×16×4=1024种组合。

**追问**：为什么测试“0+0正确”不代表“1111+0001也正确”？如果Y经过多个模块才产生，输入刚变化时能立即相信Y吗？从哪个输入到哪个输出经过的逻辑级数最多？

**验收**：保留测试结果与至少一处边界分析；进一步能指出一条可能的最长传播路径。之后再考虑寄存器、时钟或FSM，不作为当前任务。

## 练习方式

**按问题逐步探索**：自己先提出预测 → 画局部结构 → 用1～2组输入检查 → 发现矛盾再查提示或提问 → 修改模型。能解释并完成当层产物即可进入下一层，不按日期强迫完成全部项目。
