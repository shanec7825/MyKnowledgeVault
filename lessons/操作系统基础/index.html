你正在操纵什么？

01
八个开关，为什么能代表负数？
目标：区别位模式本身与它的解释规则；先点位，再解释补码。

    

      
交互式 8 位观察器8-BIT MODEL · 数学规则

        
点击任意一位切换 0/1。左起第一位在按补码解释时具有 −128 的权重。

        

        
128 / −1286432168421

        

        
无符号 unsigned255八位全部按正权重
有符号 · 八位补码−1最高位使用 −128 权重

        
11111111：八位没有变，只是读取规则不同。

      

      

        
PREDICT FIRST / 先预测
10000000 按八位补码解释，结果是多少？
做出预测后，再按 0x80 来核对。

        
并非「二进制减去位数」
对八位模式，先算无符号值 u。若最高位为 1，八位补码的值为 u − 2⁸。例如 255 − 256 = −1。只有规则变化，位本身没有变化。

02
CPU 怎样一步一步算出 2 + 3？
目标：看到函数参数进入寄存器，执行加法，并留下返回值。

    

      
三条简化指令 · 单步实验X86-64 · 教学示意

        

        
rdi · 参数 a2
rsi · 参数 b3
rax · 返回值—

        
① mov rax, rdi ; 复制 a
② add rax, rsi ; 加上 b
③ ret ; 返回调用者

        

        
PC → ① 。先猜：第 ① 条执行后，rax 会是多少？

      

      

        
PREDICT FIRST / 先预测
第一条 mov 指令会让 rax 变成什么？
预测后单步执行，观察寄存器。

        
寄存器是什么？
它是 CPU 内部速度很快的少量存储位置。这里以 Linux x86-64 常见 System V ABI 为背景，用简化代码展示 rdi / rsi 传参、rax 返回结果。真实编译器产生的指令可能不同。
