## 这门课究竟学什么？

**一条主线：** C 代码怎样变成可执行文件，在 CPU、内存和操作系统的协作下运行，最后通过文件或网络与外界交互。

![计算机系统学习主线](visuals/计算机系统学习主线.svg)

下面是**学习阶段**，不是硬性先修关卡。按当前好奇的问题进入，不需要把前面的资料全部读完。

## 每个微实验都走三层

| 层次 | 具体做什么 | 怎样判断收获 |
| --- | --- | --- |
| **A · 看见** | 在 HTML 实验台预测一次，改变一个条件 | 发现一项状态如何变化 |
| **B · 验证** | 在 Ubuntu 运行最小实验，尝试一个变式 | 有真实输出和自己的观察 |
| **C · 解释与迁移** | 按需阅读《深入理解计算机系统》相关小节，换输入复测 | 能独立解释原因和适用条件 |

## HTML 在哪里打开？

Obsidian 可以预览 Markdown、Mermaid 和 SVG，但 Markdown 预览不一定执行 HTML JavaScript。建议更新知识仓库后，**直接在浏览器打开课程目录的 [index.html](index.html)**。03–10 的网页位于 [visuals/进阶前的交互观察板.html](visuals/进阶前的交互观察板.html)，均可本地离线使用。

GitHub 文件预览不会运行脚本；需要下载本地或静态网站托管。浏览器的探索记录不会同步到 GitHub 或 Google Drive。
