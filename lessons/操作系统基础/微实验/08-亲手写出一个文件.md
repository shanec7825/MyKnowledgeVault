# 微实验 08：亲手写出一个文件

> [!success] 今天的最小目标
> 让 C 程序把一行文字写入磁盘上的文本文件，之后用 cat 读取。 不必先做原课程的大项目。

## 先预测一个现象

puts 会把文字显示在屏幕，fputs(text,f) 又把文字送去了哪里？

## 先看一张机制图

```mermaid
flowchart LR
    C[C 程序] --> F[fopen 创建或打开 note.txt]
    F --> W[fputs 向流写数据]
    W --> Z[fclose 刷新并关闭]
    Z --> T[cat note.txt 再读取]
```

> [!note] 这是简化模型
> 这张图只展示本实验关心的因果顺序，没有把真实系统的全部机制画进来。

## 在 WSL 只做一个实验

```bash
mkdir -p ~/cs-system/tiny8 && cd ~/cs-system/tiny8
cat > demo.c <<'EOF'
#include <stdio.h>
int main(void) {
    FILE *f = fopen("note.txt", "w");
    if (!f) { perror("fopen"); return 1; }
    if (fputs("hello file\n", f) == EOF) { perror("fputs"); fclose(f); return 1; }
    if (fclose(f) == EOF) { perror("fclose"); return 1; }
    puts("saved");
}
EOF

gcc demo.c -o demo && ./demo
```

然后执行 `cat note.txt`；它会读取刚生成的文件。

**你应该看见：**

```text
saved
（随后 cat note.txt 会显示 hello file）
```

> [!tip] 小提示
> 如果出现“命令不存在”“文件不存在”，先用 `pwd`、`ls`、`gcc --version` 定位问题；WSL 基础见 [[自学文档0（补）-WSL 实操衔接手册]]。
