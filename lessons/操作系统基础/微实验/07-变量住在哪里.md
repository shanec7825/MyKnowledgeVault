## 先预测一个现象

为什么两次运行看到的数字地址可能改变？它们是真实物理内存地址吗？

## 在 WSL 只做一个实验

```bash
mkdir -p ~/cs-system/tiny7 && cd ~/cs-system/tiny7
cat > demo.c <<'EOF'
#include <stdio.h>
#include <stdlib.h>
int main(void) {
    int x = 7;
    int *p = malloc(sizeof *p);
    if (!p) return 1;
    *p = 9;
    printf("local=%p heap=%p\n", (void*)&x, (void*)p);
    free(p);
}
EOF

gcc demo.c -o demo && ./demo
```

**你应该看见：**

```text
local=0x... heap=0x...（地址每次可能不同）
```

> [!tip] 小提示
> 如果出现“命令不存在”“文件不存在”，先用 `pwd`、`ls`、`gcc --version` 定位问题；WSL 基础见 [[自学文档0（补）-WSL 实操衔接手册]]。

## 现在解释，不必马上记全套概念

打印指针可以看**虚拟地址**，不能单凭这些数字证明页表映射、物理地址，也不保证各种对象的固定地址布局。
