# 数据结构｜课程阶段

> [!important] 总目标
> 遇到一个数据组织与处理问题，能选择合适结构、画出状态、推导操作、写出正确代码，解释时间/空间复杂度并设计反例测试。
>
> 采用 **独立预测 → 表示与推演 → 实现 → 验证 → 迁移** 的能力链，而非以“课看完了”判断掌握。

## 阶段 1｜线性结构：数组、顺序表、链表、栈和队列
- **核心问题**：逻辑顺序和物理存储有什么区别？改动数据时谁负责移动，谁负责修改链接？
- **学习范围**：顺序表的查找/插入/删除；单链表的带头结点/不带头结点写法；双向链表；栈与队列；空间占用与复杂度；C 指针及内存管理。
- **当前教材入口**：[[lessons/数据结构/第二章-线性表-入门诊断|第二章 · 首轮诊断]] → [[lessons/数据结构/第二章作业-边做边学指南|概念与验收指南]] → [[lessons/数据结构/visuals/第二章作业-交互实验室.html|第二章原作业交互实验室]] → [[lessons/数据结构/practice/homework-starter.c|C TODO 模板]]、[[lessons/数据结构/practice/homework-tests.c|真实测试]]。
- **区分三层证据**：网页模拟操作成功 ≠ 自己写对 C 代码 ≠ 经过边界测试独立验收。
- **验收**：独立处理严格开区间删除、数组前缀原地逆置、保持次序建链；写出 `ElemType` C 实现；能测试空表、边界、重复值、头尾结点。
- **学习证据**：[[calendar/2026-10-19#数据结构｜第二章线性表诊断启动|2026-10-19 · 第一轮独立作答与反馈]]；[[calendar/2026-10-19#数据结构｜第二章作业交互实验室与代码测试模板建立|2026-10-19 · 教学工具与测试模板准备]]。是否完成 C 代码、运行测试以实际记录为准。

## 阶段 2｜排序与查找
- **核心问题**：怎样利用“有序”“分治”等条件减少比较与数据移动？
- **范围**：顺序/二分查找，基本排序、稳定性与复杂度、边界情况。
- **验收**：能预测排序中间状态，比较不同输入情况下的性能；可实现并测试至少两种排序与二分查找。

## 阶段 3｜树、堆、散列表
- **核心问题**：怎样利用层次、优先级与映射组织信息？
- **范围**：树与二叉树遍历、二叉搜索树、堆、散列表及冲突处理。
- **验收**：能手绘增删与遍历过程，说明不变量并实现关键操作。

## 阶段 4｜图与算法策略
- **核心问题**：怎样在有连接、有成本与有约束的问题中设计并证明算法？
- **范围**：图的表示与遍历、最短路径、生成树；基础贪心、分治、动态规划。
- **验收**：能选表示方法、手推算法、识别适用条件、构造反例和估算复杂度。

## 诊断与讲解原则
- 最先进行阶段 1 的能力诊断。**交卷前不公布答案或完整教学代码**；如果卡住，先给一层提示。
- 作答后逐题反馈：**已独立掌握 / 方向正确但存在漏洞 / 提示后完成 / 尚未建立模型**，不能用单一分数替代具体证据。
- 讲解优先顺序由错误决定，例如边界理解、数组下标、指针关系、C 实现、复杂度与测试。
- 每次讲解至少有一道更换数据或条件的变式，不看原答案独立做。
- 阶段目标是相对稳定的知识，不记录无证据的“今日已学会”。
- 真实答题、提示程度、错误与测试记录放在对应的 [[calendar/2026-10-19|日期日记]]，并在阶段保留证据链接。
