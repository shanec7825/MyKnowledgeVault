## 题 1｜什么叫“顺序”？（概念）
考虑线性表 `[4, 8, 12, 16]`。

1. 顺序存储与链式存储分别怎样表达这些元素的先后次序？
2. 若在 `8` 后插入 `10`，两种存储方式各需要做什么？
3. 为什么“链表插入是 O(1)”这句话不一定足以描述**完整插入任务**的成本？请说出一个前提。

**观察点**：逻辑结构、物理存储、寻找位置与实际修改的区别。

## 题 2｜递增顺序表的区间删除（对应作业习题 1）
`L = [1, 3, 3, 5, 6, 8, 10, 10, 13]`，`k1=3`，`k2=10`。

1. 删除**严格满足 `k1 < x < k2`** 的所有元素后，`L` 应是什么？
2. 能否不创建第二个同规模数组就完成删除？请写出直觉上的操作步骤，尤其说清“读到哪里”和“写到哪里”。
3. 已知原表递增有序，这个条件怎样帮助你？分析时间复杂度和额外空间复杂度。
4. 任选一个边界测试：空表、没有元素可删、所有元素均应删除，或存在重复值。

**观察点**：开区间边界、连续存储的数据覆盖、保序、复杂度。

## 题 3｜数组原地逆置（对应作业习题 3）
数组 `A = [2, 7, 1, 8, 2, 8, 99, 100]`，`arraySize=8`，有效元素个数 `n=6`。

1. 逆置后**整个数组**的内容是什么？注意只处理前 `n` 个位置。
2. 不开新数组，画出或写出每次交换的下标对。
3. 如果 `n=0`、`n=1` 或者 `n` 为奇数，你的方法需要怎样停止？
4. 说明时间复杂度及额外空间复杂度。

**观察点**：有效长度与容量的区别、首尾指针/下标、循环终止条件。

## 题 4｜从数组正序创建单链表（对应作业习题 2）
从 `A = [8, 3, 8, 1]` 的第一个元素开始，依次创建节点，要求生成的链表从头到尾仍是 `8 → 3 → 8 → 1`。

1. 画出节点和 `next` 指针，标记头指针；你准备使用头结点还是不带头结点？
2. 每来一个元素，你将新节点接到什么位置？要保存哪些指针？
3. 如果每次都把新节点直接插到链表最前面，会出现什么问题？
4. 试用伪代码或 C 写出核心循环，说明空数组时的处理。

**观察点**：头结点、头指针、尾指针、保序与动态内存。

## 题 5｜链表改动与边界（对应不需提交的附加练习）
有头结点的单链表：
`H → 4 → 7 → 7 → 9 → NULL`。

1. 删除**第一个**值为 `7` 的数据结点，画出操作后的链接；需要改动哪一个节点的 `next`？
2. 在值为 `4` 的节点后插入 `6`，列出你认为安全的指针更新次序。
3. 对不带头结点的链表，如果要删除第一个数据结点，哪一项工作与带头结点版本不同？
4. 用一句话说明节点删除后还应怎样管理分配的内存（C 语言场景）。

**观察点**：前驱、链接不断裂、空指针、头结点与内存释放。
