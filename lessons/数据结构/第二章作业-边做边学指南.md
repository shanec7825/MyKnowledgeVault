## 由 2026-10-19 首轮诊断确定的补课内容

1. **完整插入的时间复杂度**：如果指向插入位置结点的指针已知，链表修改有限条 `next` 是 O(1)；只有头指针而需寻找位置，最坏寻找是 O(n)。说“链表插入 O(1)”必须交代前提。
2. **顺序表区间删除**：判定 `k1 < x < k2` 是严格开区间；重复的端点均应保留。逐删除逐整体前移在某些情况下可能达到 O(n²)；一次扫描以读写下标压缩，或利用有序性找连续删除段再搬移，能避免反复挪动。
3. **原地逆置**：`arraySize` 是容量，`n` 是本题处理的前缀长度；后续元素必须保持原值。一个固定 `temp` 反复交换属于 O(1) 额外空间；循环几次不等于创建几个辅助数组。
4. **链表指针**：单链表数据结点一般有 `data` 和 `next`；头指针不等于可选的哨兵头结点；尾指针能使正序追加变得直接。头插可能导致倒序；删除首结点时无头结点版本需要更新头指针。
5. **未核实的原答**：此前“828，172”的表述暂按 `[8,2,8,1,7,2]` 理解，不能把这一推测当作已经用户确认。

## 老师原作业：三题任务

### 习题 1｜递增顺序表删除严格区间
- **独立写**：原表中哪些数应当保留？对等于 `k1` 或 `k2` 的值怎么办？
- **重点**：顺序表的 `length`、读取下标/写入下标、覆盖原数组元素、增序条件与复杂度。
- **核验**：正常删除、无可删除项、全删、空表、重复的边界值。

### 习题 2｜按数组次序正序创建单链表
- **独立写**：从 `A[0]` 读取起，每次新结点接哪里？第一次建立时头指针如何变化？
- **重点**：`head`、`tail`、`next`、`malloc` / `free`、带头结点与不带头结点之别。
- **配套 C 契约**：练习模板选择不带头结点，空数组返回 `NULL`；原题本身未限定必须使用哪一种。

### 习题 3｜将数组前 n 个位置原地逆置
- **独立写**：有效前缀下标范围、首尾配对、临时变量、何时停止？
- **重点**：不可改动数组后缀；支持 `n=0`、`n=1`、奇偶长度；分析 O(n) 时间与 O(1) 额外空间。

### 不提交的附加练习
带头结点与不带头结点的单链表“读取、插入、删除”。先画指针图，解释为何不会断链，最后再写 C 实现并释放不再使用的结点。

## 老师要求的提交结构

- 人的思路：手工处理步骤与理由。
- 计算机的思路：使用的变量、下标、结点、指针、循环与终止条件。
- 题目指定存储方式：该存储结构下应该怎样处理。
- 顺序存储与链式存储对比：查找位置、移动或修改链接、开销与适用条件。
- C 代码：数据元素以 `ElemType` 表示，测试时用 `typedef` 明确其具体类型。
- 测试证据：输入、预期输出、**实际运行输出**与发现问题后的更正。
