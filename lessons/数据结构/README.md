## 本课的最小学习闭环

1. **预测**：独立写出结果、理由与可能的边界条件。
2. **建模**：在纸上画数组下标/链表指针，说明人会怎样做、机器怎样执行。
3. **实现**：优先 C 语言；依据作业要求使用 `ElemType`，测试时用 `typedef` 具体化。
4. **验证**：至少一组正常案例、一组边界案例，附输入、预期结果与实际结果。
5. **迁移**：比较顺序存储与链式存储，在改动约束后重做，而不是背参考代码。

## 课程依据

2026-10-19 上传的《数据结构第二章课后作业.doc》，涵盖：
- 已按递增顺序存储的顺序表，删除严格位于 `k1` 与 `k2` 之间的元素；
- 从数组左到右**正序**创建链表；
- 数组前 `n` 个元素**原地逆置**，只用常数额外空间；
- 带头结点与不带头结点单链表的读取、插入和删除（练习题，不需提交）。

作业要求写清“人的思路”和“计算机的思路”、特定存储方式的做法、顺序/链式差异、`ElemType` 代码，以及测试用例与结果；在尚未完成诊断前不提前写出整套标准解答。
