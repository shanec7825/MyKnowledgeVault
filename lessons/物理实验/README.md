# 物理实验｜课程入口

> [!abstract] 学习主线
> **先预测 → 调仪器观察 → 留下读数 → 解释差异 → 换一个条件复测。** 学习资料的生成不是实验已完成的证据。

## 实验 3.1｜示波器的使用

1. [[实验3.1-示波器的使用-自学指南|自学指南：从波形、触发到李萨如图]]：每个概念先解释它的**作用**，再展示结构、公式、实验操作和检查点。内嵌三类 Mermaid 图。
2. [[实验3.1-示波器的使用-报告辅助与核验|实验报告辅助与核验]]：逐条对应报告两页的设置、读数、待填表格、误差和自检，**理论预期与实测严格分开**。
3. [交互式示波器实验室（HTML）](visuals/示波器与李萨如图-交互实验室.html)：浏览器打开，可调正弦/三角/方波、频率、幅度、偏置、时基、触发条件与 X-Y 图；含中文语音讲解和**可听频段**音调对比。

> [!tip] Obsidian 使用
> Markdown 文件在 Obsidian 阅读，Mermaid 代码块在 Obsidian 阅读视图显示。HTML 文件需**从系统浏览器打开**才能正常运行 JavaScript；Obsidian 内直接预览不一定启用脚本。HTML 不加载远端 JS、字体或音频资源，但语音朗读依赖浏览器和操作系统可用的中文语音。

## 不增加第二套学习状态

本目录只存稳定、可复用的课程资料。真正做实验的当天，再在 calendar 日期日记记录仪器型号、参数、照片、实测值、误差、独立解释与下一次启动线索；无实验记录则不判定为掌握。

## 本课程的三个通用能力阶段

| 能力 | 你能独立做什么 | 证据 |
| --- | --- | --- |
| 原理与测量 | 说明仪器测什么、横纵轴是什么、设置怎样改变读数 | 波形预测、带单位的原始记录 |
| 数据处理 | 用格数与刻度计算电压、周期、频率、占空比；辨析系统误差 | 手算 + 仪器自动测量核对 |
| 结果解释 | 解释触发失败、双通道不同步、X-Y 轨迹，说明理论和测量不一致的来源 | 设置记录 + 假设 + 复测 |
