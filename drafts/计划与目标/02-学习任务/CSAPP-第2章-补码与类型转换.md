# CSAPP-第2章-补码与类型转换

所属：[[计算机系统基础|计算机系统基础]]　阶段：项目 1 / CSAPP 2.1–2.3

> [!warning] 初始证据
> 已讨论“位模式、补码是什么”；尚无独立对新输入推导的记录。
> **status = doing** 仅说明任务的规划/跟进状态；目前安排的是诊断性复习，不代表之前通过验收。

## 学习目标
理解固定宽度的位串、无符号数与补码之间的映射，以及转换导致的行为变化。

## 可执行步骤
- [ ] 手算 8 位 11111111、10000000 在 unsigned 和 two's complement 下的值。
- [ ] 预测 8 位截断、零扩展/符号扩展以及 signed/unsigned 比较的结果。
- [ ] 编写最小 C 实验打印字节和转换前后结果，解释语言规则与位模式。

## 验收标准
- [ ] 不查资料推导 w 位补码范围，并解释最高位负权。
- [ ] 预测至少 3 个新输入，再运行对照，无明显概念性错误。
- [ ] 能描述不安全的有符号溢出与无符号模运算的差异。

## 时间建议
45–60 分钟（仅供安排，不用学习时长代替验收）。
