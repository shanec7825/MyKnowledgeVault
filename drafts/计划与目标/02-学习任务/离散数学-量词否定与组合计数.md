# 离散数学-量词否定与组合计数

所属：[[离散数学|离散数学]]　阶段：逻辑与计数

> [!warning] 初始证据
> 多次提问量词德摩根律、复杂对象条件和组合计数；没有独立整组练习记录。
> **status = todo** 仅说明任务的规划/跟进状态；当前未获得独立完成的可核实证据。

## 学习目标
在遇到陌生符号时保持逻辑作用域，避免把部分否定误认为整体否定。

## 可执行步骤
- [ ] 把 3 句含两个量词的中文命题形式化，再逐层否定。
- [ ] 对“所有对象中至少存在一个...”构造具体小集合反例。
- [ ] 做 3 道先选再分情况的计数题，写明是否重复/遗漏。

## 验收标准
- [ ] 准确指出量词作用域、否定后的量词顺序。
- [ ] 计数题能解释分类完备且互斥的理由。

## 时间建议
35–50 分钟（仅供安排，不用学习时长代替验收）。
