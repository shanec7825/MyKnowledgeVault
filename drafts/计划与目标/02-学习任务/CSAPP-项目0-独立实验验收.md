## 学习目标
确认项目 0 不是“看过文档”，而是已经亲自观察构建与运行过程。

## 可执行步骤
- [ ] 用自己的 C 源文件保存 .i、.s、.o 和可执行文件，并说明每个产物。
- [ ] 使用 file、nm/objdump、gdb、strace 与 /proc 至少各得到一条证据。
- [ ] 绘制从源文件到进程的流程图，写下一次与预测不同的观察。

## 验收标准
- [ ] 解释源文件、目标文件、可执行文件、进程之间区别。
- [ ] 给一个新 C 程序，能自主选工具验证某一假设。
- [ ] 保留命令、输出和解释，而非只有截图。

## 时间建议
50–70 分钟（仅供安排，不用学习时长代替验收）。
