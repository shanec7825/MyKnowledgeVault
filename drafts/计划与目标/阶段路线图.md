# 各方向分阶段学习路线图

**十一门不是同时推进的任务清单。** 没有日期、周计划或完成率；想学哪门就看哪门的当前阶段。

## [[计算机系统基础|计算机系统基础]]
1. **从源文件到进程**：C程序和构建/运行观察记录。
2. **数值与位模式**：位模式实验与浮点实验。
3. **机器运行与性能**：汇编对照、CPU轨迹、性能实验。
4. **操作系统抽象**：Shell、内存观察、文件复制实验。
5. **网络并发与综合**：可运行Mini Linux Web Server及测试报告。

## [[数据结构与算法|数据结构与算法]]
1. **线性结构与抽象**：实现两种结构并测试边界。
2. **排序与搜索**：独立实现与比较排序和查找。
3. **树堆散列**：测试或实现堆、散列表。
4. **图与策略**：解决图问题及DP问题。

## [[数字逻辑与系统|数字逻辑与系统]]
1. **编码与布尔模型**：化简并验证逻辑表达式。
2. **组合模块**：实现一个小型组合模块。
3. **时序与状态机**：设计四状态FSM并比较编码。
4. **处理器结构**：模拟一个简化CPU逐步执行。

## [[离散数学|离散数学]]
1. **逻辑与量词**：多对象命题翻译、否定、验证。
2. **集合关系与证明**：独立完成一组证明。
3. **计数与递推**：完成多条件计数题。
4. **图与离散概率**：对实际问题建模。

## [[全国大学生数学竞赛|全国大学生数学竞赛]]
1. **极限函数与连续性**：重做代表例题并对比不同解法。
2. **微分与中值定理**：典型计算与证明题。
3. **积分专题**：计算题与证明题。
4. **无穷级数**：用不同判别法解决新题。
5. **综合竞赛能力**：完成陌生综合题并保留首次思路。

## [[计算机网络与后端|计算机网络与后端]]
1. **请求全链路**：画实际请求路径并用日志验证。
2. **数据与服务**：为已有接口补测试与错误处理。
3. **网络机制**：分析真实传输或系统调用。
4. **部署与并发**：复现一次故障并给排查报告。

## [[英语|英语]]
1. **理解内容结构**：闭卷说出一篇文章的问题与结论。
2. **口语复述与语音**：不看稿复述一段材料。
3. **独立写作**：写一篇短文并自行修改。
4. **跨情境迁移**：跨话题解释和讨论。

## [[AI与深度学习|AI与深度学习]]
1. **计算图与自动微分**：复现micrograd并验证梯度。
2. **神经网络训练**：训练小模型并画曲线。
3. **注意力与Transformer**：实现最小注意力模块。
4. **小型语言模型**：建立小模型基线对照实验。
5. **独立复现**：可重复的模型项目。

## [[音乐基础|音乐基础]]
1. **节拍与节奏**：跟拍并模仿不同节奏。
2. **音高与音程**：键盘找音和简单听音。
3. **音阶和和弦**：构建音阶与基本和弦。
4. **歌曲与创作**：分析歌曲并创作短乐句。

## [[物理实验|物理实验]]
1. **实验原理与测量**：完整标注实验原始数据的来源。
2. **处理与不确定度**：完成可复算的数据表。
3. **结果解释与报告**：独立写可复核实验报告。

## [[跨学科学习方法|跨学科学习方法]]
1. **术语角色识别**：标注四个学科的陌生术语。
2. **上下文机制**：画句子或段落关系图。
3. **主动提取和反例**：针对新术语给出例子和验证。
4. **独立阅读**：完成一段陌生材料的独立分析。
