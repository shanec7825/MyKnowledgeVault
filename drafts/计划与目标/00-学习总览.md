# 学习总览｜只看阶段

> [!important] 无需每天制定任务
> 只管理每个方向当前研究什么、如何判断阶段完成。旧的日计划和每周复盘不再需要执行。

- [[阶段路线图|所有方向的阶段图]]
- [[drafts/计划与目标/README|使用方法]]

## 推荐关注方向
```dataview
TABLE phase AS "当前主题", current_stage AS "建议阶段", stage_status AS "验收"
FROM "drafts/计划与目标/01-课程目标"
WHERE type = "course-goal" AND (track_mode = "main" OR track_mode = "light")
SORT file.name ASC
```

## 所有阶段入口
```dataview
TABLE current_stage AS "阶段", stage_count AS "总阶段", phase AS "主题", stage_status AS "状态"
FROM "drafts/计划与目标/01-课程目标"
WHERE type = "course-goal"
SORT file.name ASC
```

## 阶段前进标准
能**不看资料解释核心机制**，能独立做一次题目/实验/表达验证，并在新输入下迁移，才考虑把阶段标为 `verified`。完成多少篇资料不等于实际掌握。

> [!note] `02-学习任务` 已降级为可选练习库，过去的任务日期视为历史建议，不再用来生成今日清单。
