## Key Recent Facts

- 认知表征与泛化：理解力 = 图式/概念结构（部分成立）；「区间」等词根植于具身经验（概念隐喻 + 心理数字线）；具身认知有复制危机（模拟非必要）；元认知/迁移可训练（SRL g≈0.38-0.48）；泛化不只有空间格式（LoT/关系范畴）。
- 学习方法认知科学验证：日记 5 条论断中，「误差适度」与「间隔/睡眠/运动巩固」获实证支持；「深入必致遗忘」被存储/提取强度理论与节省效应部分反驳；「框架先行」与「两类概念」二分证据较弱（contested/provisional）。
- RL/DL 类比认知框架：6 阶段认知流水线（接触→编码→输出→反馈→修正→巩固）、12 项核心原则、5 个概念维度（RL→学习、DL→记忆、训练→推理、生成→创造力）。研究档案状态，尚未进行 canonical merge。
- DNS 解析五步流程：本地缓存 → 递归 DNS → 根服务器 → TLD 服务器 → 权威服务器。dig 工具（查询/追踪/DNSSEC/指定服务器）、whois 查询域名注册信息。
- 域名结构从右向左读（子域.SLD.TLD），标签最长 63 字符，ICANN 管理完整 TLD 列表。域名是「租用」而非「购买」——只能获得一定年限的使用权。
- Backend Introduction 项目现已覆盖：互联网原理 / HTTP / HTTP/3 / Web 浏览器 / 浏览器渲染管道 / 域名 / DNS——网络基础层基本完整。
- 域名：人类可读的 Web 服务器地址，租用而非购买；结构 = label（1–63 字符）+ TLD（.com/.org/.net 通用，.gov/.edu 受限）；DNS 把域名翻译成 IP（浏览器→本地缓存→DNS 服务器）。
- 机器学习（ML）：AI 子集，三大范式（监督 / 无监督 / 强化）；深度学习以 Transformer 为生成式 AI 基石；ML 逻辑从数据中隐式习得，区别于规则型 AI。
- 成人可塑性：存在但更弱且领域特异；海马神经发生存在性、n-back 训练迁移、二语关键期曲线形状三组并列矛盾（contested）。
- 认知迁移：交错练习 (d=1.34)、提取练习 (d=0.40) 有实证支持；远迁移整体稀缺但有条件存在。
