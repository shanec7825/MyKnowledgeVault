/ɪˈvoʊk/

- **词性**：动词
- **核心意义**：某个声音、场景、文字或经历唤起一种记忆、画面、情绪或反应。
- **核心关系**：stimulus / event → brings out memory / image / emotion / response
- **常见搭配**：evoke a memory · evoke an image · evoke an emotional response · evoke a sense of ...
- **主动调用情境**：描述音乐、文字、气味或场景让脑中出现某种感受或画面。

> This melody evokes a vivid image in my mind.
