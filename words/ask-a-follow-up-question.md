# ask a follow-up question

**Meaning:** ask a question that builds on something the other person has just said.

**Pattern:** ask a follow-up question **about** a detail; follow up **on** an answer.

**2026-10-21 context:** If a classmate says they are building a robot, ask a follow-up question: “What has been the hardest part?”

**Recognition → retrieval:** “追问一个承接上文的问题” → ask a ___-___ question.

**Transfer:** Turn “Do you like music?” into a more open question, then ask a relevant follow-up.

**Contrast:** An unrelated new question changes topics; a follow-up shows you heard the earlier answer.
