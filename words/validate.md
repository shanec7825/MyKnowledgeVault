/ˈvælɪdeɪt/

- **词性**：动词
- **核心意义**：用证据、实验或现实数据检验一个模型、方法或假设是否得到支持。
- **核心关系**：model / idea → test against evidence → stronger support
- **常见搭配**：validate a model · validate an assumption · experimentally validate
- **主动调用情境**：我不能只觉得模型合理，还需要拿现实数据检验它。

> We should validate the simulation against real measurements.
