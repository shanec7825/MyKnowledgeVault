# jog someone's memory

**Meaning:** cause someone to remember something; a **cue for recall**, not proof of comprehension.

**Pattern:** jog my / your / someone's memory (of / about something).

**Example:** A familiar melody might jog my memory of a short English phrase.

**Chinese → English retrieval:** “这张图可能唤起我对那个 Linux 命令的记忆。” → This picture may ___ my ___ of that Linux command.

**New-context transfer:** Name one cue that could jog your memory during a basketball drill.
