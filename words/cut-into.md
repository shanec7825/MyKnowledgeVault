# cut into ...

**Meaning:** reduce the time, money or resources available for something.

**Pattern:** cut into + sleep / study time / budget / free time. Past tense is also **cut**.

**Meaning → English:** “熬夜调试占用了我的睡眠时间。” → Late-night debugging ___ ___ my sleep time.

**Original context:** Late-night group work can cut into a student's sleep.

**Transfer:** Unexpected server maintenance cut into the time available for code review. This describes lost time, not a measured learning outcome.
