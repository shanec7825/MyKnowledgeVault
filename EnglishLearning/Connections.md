## Reading Framework Network

```text
Background
   ↓
Problem / Question
   ↓
Method / Approach
   ↓
Result
   ↓
Interpretation
   ↓
Implication
```

同时允许其它真实结构：

- **Expectation → Failure → Cause → Solution**
- **Structure → Input → Mechanism → Output**
- **Claim → Evidence → Limitation**
- **Before → Change → After**
- **Cause → Effect**
- **General idea → Example**

核心识别问题：

> **What is the writer doing here?**

## Discourse Signals

- **but / however** → update or revise the current model
- **because / due to** → cause
- **therefore / so / as a result** → consequence
- **for example / for instance** → supporting detail
- **while / whereas** → contrast or simultaneous dimensions
- **suggest / may indicate** → interpretation rather than direct proof

## Active Expression Network

### Improve / Change

- [[words/refine|refine]] — make something existing more precise or better
- [[words/threshold|threshold]] — the point at which a state changes or something becomes possible

### Reduce Effectiveness

- [[words/undermine|undermine]] — make something less effective or successful

### Previously Practiced Retrieval Cues

- **get stuck** — cannot move forward
- **rely on** — need something in order to work
- **scale** — continue to work when size/load becomes much larger
- **in response to** — something happens because of a stimulus/event

## Weekly Synthesis · 2026-09-24 → 2026-09-30

### Main reading bottleneck to keep testing
**Local comprehension may be stronger than global-model retention.**  
训练重点不是强迫记住原句，而是持续回答：

> What is the writer doing here?  
> What relationship connects this paragraph to the previous one?

### Frameworks practiced
1. Question / Method / Result / Interpretation
2. Evidence vs Interpretation
3. Before vs After
4. Method vs Mechanism
5. Cause → Effect
6. Expectation → Failure → Cause → Solution

### Retrieval strategy
新表达不只做 English → meaning，而要重复做：

**context / meaning → English**

并在至少三个不同情境中复用：原文、生活、计算机/学习。

### Expressions to retest rather than assume mastered
**get stuck · keep track of · underlying · suggest that · in response to · scale · without sacrificing**

> 是否进入主动词汇，要以后续“不给英文提示时能否调用”为准。

## Review Rule

每天新文档至少完成三种连接：

1. **Previous-day link** — 与前一天训练连接。
2. **Expression link** — 与已有主动词汇连接。
3. **Concept link** — 与另一篇文章的结构、论证或主题连接。

每 7 天在本页新增一次 Weekly Synthesis：
- repeated bottlenecks
- expressions that can be actively retrieved
- reading frameworks that are becoming automatic
- themes that appeared across different domains
