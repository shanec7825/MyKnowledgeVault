# Daily English shared UI

The static HTML companions share this lightweight CSS/JS enhancement, inspired by shadcn/ui design tokens and button/card/accordion patterns. A reusable React navigation component renders when React/ReactDOM are available; an accessible, offline DOM fallback keeps pages functional in Obsidian without a build pipeline. Images are original topic-specific SVG storybook illustrations; no external credentials or MiMo calls are included. Source article text and original lesson exercises remain within each HTML file.

The audio policy is publisher-first. When no verified direct audio is present, link to the publisher player and transcript and use the Obsidian MiMo English Coach plugin to synthesize speech through its secure configuration. Never embed keys in client-side HTML.
