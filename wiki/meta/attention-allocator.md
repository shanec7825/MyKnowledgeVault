# 注意力分配器

一个结合现有 [[wiki/meta/agent-search|QMD 检索]] 与本地 Mem0 的桌面 Obsidian 插件。0.2 版参考已安装 Thino 的轻量输入框、时间卡片和主题配色；从当前兴趣出发，通过图片、资源、代码、故事等内容，把注意力过渡到相近的成长活动。安装目录为 `.obsidian/plugins/attention-allocator/`，插件 ID 为 `attention-allocator`。

## 开始使用

1. 命令面板运行「Attention: Open Attention」，或点击左侧 focus 图标。
2. 点击首页右上角 `··· → 设置 / Settings`，在个人画像与成长方向（`Profile` / `Directions`）填写背景；Agent 同时结合已有记忆、近期活动及最近两篇日记理解背景，不需要每次重新选择。右上角 `中文 / EN` 切换界面语言，设置中也可选择；不翻译或重写已有笔记内容。
3. 选择小米 Token Plan 的集群，在密码框输入自己的 `tp-` 套餐 Key 并点击 `Save key`。地址以小米套餐页面为准。
4. 模型默认 `mimo-v2.6-flash`，可改为账户支持的其他模型。点击 `Test` 会消耗少量额度。
5. 回到首页只说此刻的想法，点击「继续 / Continue」，或 Ctrl / Cmd + Enter。输入区 `+` 收起保存、反省和可选检索关键词。
6. 先体验过渡内容，再顺势进入相关活动。完成后留下成果，也可以保存停下的位置。无需选择发散/集中：它们只是 Agent 内部的内容策略。纠正反馈可以帮助 Agent 换一种过渡方式。

## 注意力如何过渡

近期活动、人设、日记和 Mem0 提供背景，此刻输入提供兴趣锚点。引导允许跨领域联想、画面、情绪、反例、陌生资源和暂时没有用途的探索。先提供值得体验的内容，再轻轻邀请下一步；不要求证明兴趣与成长任务的必然关联，也不把每种爱好硬拐回待办。没有明确执行意愿时优先开放探索，适合时给两三个真正不同的问题；明确想实践时再收敛。内部仍保留兴趣与方向字段，但日记正文不展示机械的箭头推导。

图片由独立兼容 `/images/generations` 的接口生成，需在设置中填写 Base URL、模型和独立 Key；Agent 判断需要图片且接口配置完整时会自动调用。Base64 图片保存到 `calendar/assets/`；服务返回公共图片 URL 时展示原 URL。小米套餐 Key 不会发送到图片接口。

`Web search` 仅在独立按量付费 API 下发送原生搜索工具，须启用小米搜索服务，可能有独立费用。[官方联网搜索说明](https://mimo.mi.com/docs/en-US/usage-guide/tool-calling/web-search)。2026-10-07 在当前中国 Token Plan 集群与 `mimo-v2.6-pro` 上实测：普通 JSON 生成返回 200；加入原生 `web_search` 返回 400 `Param Incorrect`。因此套餐请求不发送该工具，保持原套餐地址与 Key，并提示提供的是资源搜索入口；不会自动切换按量付费，也不将搜索入口冒充已检索资源。

首页由独立输入区与日记卡片组成，一次只展示一张对话卡片。默认是今天最近的一段对话；左右的露边纸片、卡片底部箭头可切换同一天的对话，下方露出的日期纸片与上下箭头可切换日期，带淡入与移纸动画。聚焦纸堆后可用方向键；左右滑动也可翻对话。尊重系统减少动画设置。长回复在卡片内滚动，不挤走翻页控件；手写的时间记录和无时间正文仍保留，后生成的图片归入原对话卡片。新回复自动回到今天对应的对话，浏览旧日期不会改写输入草稿。

右上角 `···` 统一收起记忆、检索、最近活动、资料库、设置，最近与资料库在独立窗口中查看，不再占据首页。旧活动可定位到对应日期卡片，未归档内容在只读窗口打开。输入区的时间数字展开番茄钟：专注 25 分钟 / 休息 5 分钟，支持开始、暂停和重置；关闭页面后继续按实际时间计时，状态本地保存，到时提醒而不自动开始下一轮。

右上角「AI 引导 / 纯记录」（`AI guidance / Record only`）可切换输入方式并保存选择。纯记录直接写入用户 callout，不检查密钥、不召回记忆、不触发 AI 回复；恢复 AI 引导也不会自动发送现有草稿。纯记录条目带本地标记，后续插件 AI 上下文与总结排除这些正文，但仍作为日记显示、保存在本地索引中；这是本插件的读取约定，不会限制其他插件。仅在 AI 开关的小圆点和日期短线使用少量绿色，不染色整张纸。

鼠标滚轮在纸堆区域上下换日期，横向滚动或 Shift + 滚轮左右换对话。长正文先滚动阅读，到边界后才翻日期；缩放手势、代码区域不会被拦截。翻页设置阈值与短暂防抖，避免一次滚动连续翻很多张。展开菜单、附加输入项、番茄钟或更多操作后，点击外部空白或按 Escape 收起；点击面板内部保持展开，独立窗口也支持点击外部关闭。

## calendar 日记与长期记忆

- `Save` 把原始想法写入当天日记，不需要模型 Key。
- `Continue` 获得完整有效回复后，立即把用户想法与 AI 回复保存到当天日记，无需先点击 Done。`> [!quote] Me` 区分用户记录，`> [!tip] AI` 区分 AI 内容，支持代码、资源链接与图片。
- 日记保存成功后清空已提交的输入及草稿；等待期间写下的新想法不会被清空。保存失败保留输入，回复已在本地活动中保存，并提供 `Save to journal` 重试，同一回复不会重复写入。
- 输入区 `Reflect` 保存自己的反省；完成或暂停后的实践输出默认追加为新的用户 callout，`Save outcomes to journal` 可关闭这部分追加，不能关闭回复归档。
- 日期切换区的「回顾 / Review」读取当天用户记录，排除之前的 AI 总结；生成的回顾单独标注，核对、编辑后保存，不自动写入长期记忆。AI callout 是建议，不当作用户已经完成的事实。
- 日记保留 `- HH:mm` 时间记录，按上海时区定位 `calendar/YYYY-MM-DD.md`。新 callout 用独立引用块避免缩进被原生编辑器识别为代码块；只修正带插件标记的此类旧缩进，保留正文与手写记录。对同一记录去重；同步维护 [[calendar/README|日记目录]] 和 QMD。原有普通 Thino 记录仍可显示。
- 日期日记发生编辑、创建或删除时刷新卡片；跨日时正在浏览今天的页面会切换到新一天，历史浏览保持原日期。生成图片完成后追加 AI 图片记录，展示时并入原对话。
- 日记保留经历和输出；现有 Mem0 保存确认过的长期偏好。近期日记会成为后续过渡内容的背景，自动记忆提取仍遵守原设置。

没有小米 Key 时，知识库概览、最近活动和「检索本库」仍可使用。

## 检索与记忆如何复用

QMD 直接使用 `.qmd/index.yml`、`.qmd/index.sqlite` 和 `.vault-meta/search/`。每次检索前增量 update；默认关键词检索。可开启语义混合检索，先补齐本地嵌入，再使用 `lex` / `vec`、`--no-rerank`。不启用自动扩写，不下载扩写或重排模型。命中后读取原笔记片段；来源按钮可打开实际路径和行号。只检索 `vault` collection；本地 `raw` 材料本版不发送给模型。

首页 `Search` 打开独立检索窗口，不覆盖当前行动卡片。可选择全部笔记、知识笔记或日记范围，显示最多五个相关结果、真实文件路径与原文片段，点击标题跳转到原文件和对应行。生成引导时单独检索非 calendar 的知识笔记，再补充最多两篇近期日记；Context 分组显示两者，没有匹配时明确显示空结果，不用日记填满知识区域。旧对话保留生成时的来源，不自动改写历史上下文。`calendar` 日记与配置中的课程、英语、音乐、数学、wiki、草稿及根目录 Markdown 均可检索；PDF、图片、HTML 和 Excalidraw 压缩正文不在 QMD 文本覆盖范围。文件变化时先 update；语义模式还会增量补齐嵌入。

Mem0 复用 `http://127.0.0.1:8767`、`.vault-meta/memory/local-token.txt` 和现有共享用户范围 `lenovo`。服务没启动时调用已有 `start_memory.ps1`，不创建新的记忆数据库。插件会检索相关记忆；你可以通过「编辑并记住」保存一条确认过的长期偏好。

首页 `Memory` 读取现有 `/memories` 列表，显示事实与来源，支持本地筛选和刷新。提供启动服务、自动提取开关与提取最近对话按钮；状态显示本地服务就绪情况和待提取数量。服务最多返回 1000 条；窗口一次显示筛选结果中的前 100 条。浏览不会向小米发送记忆。

`Memory → Import ChatGPT` 可粘贴已有的 ChatGPT 保存记忆，每行一条；点击 `Review` 后勾选要保存的条目，再点击 `Import selected`。按文本去重，通过现有 `/add` 明确事实接口保存，来源为 `chatgpt-memory-import`，不调用模型重新推断。最多 100 条、每条 4000 字符；失败会报告已完成数量，重试跳过已写入的相同文本。当前连接器没有 ChatGPT 已保存记忆读取接口，浏览器也没有可访问的 ChatGPT 登录页面，因此未自动导入任何云端记忆。[官方记忆管理说明](https://learn.chatgpt.com/docs/customization/memories)。

自动提取（`Auto learn`）在本库已开启。AI 对话完整回复保存后，自动提交用户输入到现有 `/capture` 队列；完成/暂停后另行提交用户实际反馈，避免把 AI 建议当成用户经历。插件加载时按此设置启动既有本地服务，对话与反馈各自去重；失败明确提示，可在 Context 点击提取这段对话重试。纯记录不进入队列。排队成功与新增长期记忆不同：本地 Mem0 会筛选事实、偏好与目标，普通问句或临时想法可能不形成长期记忆，可在 Memory 刷新确认。它不修改 Codex 内置记忆；ChatGPT 手动导入是独立的一次复制，不自动双向同步。现有 Mem0 备份策略继续适用。

## 数据与模型调用

| 数据 | 保存位置与用途 |
| --- | --- |
| 行动、反馈、继续位置、输入草稿、最近打开 | `.vault-meta/attention-allocator/state.json`；最近 100 次行动、30 次打开记录；不进 QMD |
| 长期个人偏好 | 现有 Mem0；与其他已接入客户端共享 |
| 插件设置 | `.obsidian/plugins/attention-allocator/data.json`；不提交 Git |
| API Key | 系统支持时通过 Electron safeStorage 加密；否则仅保留本次会话；也支持 `MIMO_API_KEY` |

每次点击生成才调用小米。输入、人设、当前方向、最近六次活动摘要会作为上下文；最近两篇日记与相关笔记合计最多五篇，每篇约 2400 字符；记忆最多五条。设置中可分别关闭向小米提供笔记（含日记）或记忆。AI 回顾由你主动点击，使用当天非 AI 总结记录的最后约 18000 字符。常见 Key 字符串会在活动和上下文中隐藏，但不要把凭据输入注意力框。

首页 `Continue` 使用 SSE 流式输出：逐步显示标题、回应与内容，生成阶段用纯文本展示，完成并通过结构校验后保存活动和日记，在今天的纸张中渲染原生日记内容，不重复展示另一份回复。`Cancel`、网络中断、截断或无效 JSON 不保存未完成活动。AI 日记回顾和图片接口仍为完成后展示。

小米配置支持以下 OpenAI 兼容地址，使用 `/chat/completions` 与 JSON mode：

- 中国 Token Plan：`https://token-plan-cn.xiaomimimo.com/v1`
- 新加坡 Token Plan：`https://token-plan-sgp.xiaomimimo.com/v1`
- 欧洲 Token Plan：`https://token-plan-ams.xiaomimimo.com/v1`
- 独立按量付费：`https://api.xiaomimimo.com/v1`，使用独立按量 Key，不能混用 `tp-` 套餐 Key。

参考：[小米接入与鉴权说明](https://mimo.mi.com/docs/en-US/quick-start/faq/api-integration)、[结构化输出](https://mimo.mi.com/docs/en-US/quick-start/usage-guide/text-generation/structured-output)。

## 本版能力与验证

已支持文字、代码块、Mermaid 图示、独立图片接口、资源入口、可选小米联网搜索和系统语音朗读。代码展示后由你决定如何使用；不自动执行代码，小米云端 TTS 尚未接入。最近修改表示文件变化；最近打开从插件启用后开始记录，均不等于学习进度。

已通过 32 项核心自动测试，包括独立对话切分、手写记录保留、时间排序、后生成图片归入原对话与空日记。真实 Obsidian 卡片检查覆盖单对话显示、横向翻页、跨日翻页、日期纸片选择、中英文切换与草稿保留；截图确认露边纸片与底部日期堆叠。此前流程检查已覆盖 QMD 原文读取、Mem0 浏览和召回、日记检索与文件跳转、自动回复归档、callout 和代码渲染、清空提交输入与保留新草稿、开始/暂停/完成及落盘、番茄钟控制。原生日记阅读视图已确认 Me 与 AI 分别渲染为引用和提示 callout。当前中国套餐 `mimo-v2.6-pro` 已成功流式返回符合结构的注意力过渡内容；一次短测试约 0.6 秒收到首段，29 秒完成，耗时不保证固定。图片接口、AI 回顾、原生联网来源和导入写入有模拟测试；测试回复只写内存虚拟日记，没有用测试事实污染真实日记或 Mem0，也没有自动取得 ChatGPT 云端记忆。

## 维护与故障

- QMD 不可用或 Mem0 不可用时，首页会明确提示；仍可用其余上下文生成动作。
- 设置中的「刷新索引」依次执行 update、增量 embed、status；失败停止后续步骤。首次语义检索可能需等待本地嵌入。
- 状态文件格式损坏时插件暂停，防止覆盖已有数据。先备份状态文件再排查。
- 源码入口是安装目录中的 `plugin.js` 与 `core.js`；运行 `node .obsidian/plugins/attention-allocator/build.cjs` 生成 `main.js` 后重新加载插件。
- 停用插件不会删除现有 Mem0 或 QMD 数据；活动状态保留在 `.vault-meta/attention-allocator/`。
