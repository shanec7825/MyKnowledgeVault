# 计算机基础

## 领域概览

**特征**：CS 本科的「骨架课」群——数据结构与算法、计算机组成原理、操作系统、编译原理。它们回答同一类问题：**计算机内部到底怎么运转**。抽象层次分明，但概念之间强耦合：哈希表同时出现在数据库索引、OS 页表、编译器符号表里；栈同时出现在函数调用、表达式求值、撤销重做里。所以这门领域**不适合孤岛式学习**，必须靠「关联」把点缝成网。

**目标**：

建成一张**可生长的计算世界地图**：看到问题能想到表示，看到表示能想到操作，看到操作能想到代价，看到代价能做出权衡。最终状态——面对一个没见过的规模/约束组合，能独立选型并说清为什么，而不是背结构名字。

**范围**：

- **数据结构与算法**（当前主线）——线性表、栈/队列、树、图、散列、排序、查找、复杂度分析。
- **计算机组成原理**——数据怎么在硬件层被表示与运算。
- **操作系统**——进程、内存、文件系统怎么管理资源。
- **编译原理**——程序怎么被分析和生成。

> 计算机网络已在 [[wiki/areas/后端|后端]] 领域下推进（Backend Introduction / HTTP / DNS 一条链路），本领域不再重复建设，只在关联处互指。
