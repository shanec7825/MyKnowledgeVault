01领域概览
特征

以「请求 → 服务 → 数据」这条链路为主线。上游是网络协议与 API 契约，中游是服务端业务逻辑，下游是数据存储。实践性极强——看懂不等于会写，必须落到真实仓库的联调与交付上。

目标

建成一个能自我维持、持续演进的后端工程能力底盘：遇到陌生的后端问题，能自己拆解、定位、学会并交付，而不是靠教程逐条喂养。最终状态——能独立设计并交付一个完整后端服务，并能在真实团队中承担开发职责。

范围

网络基础（互联网 / HTTP 1.1~3 / DNS / 域名 / 浏览器渲染）· Web API 风格与设计 · 关系数据库（PostgreSQL）· 服务端语言与框架（Kotlin/Ktor、Python、JavaScript）· 工程协作（git、联调、代码评审）。
