## 前置
**前置项目**：无

**知识框架体系**：概念层（重力倾斜物理、多层立方迷宫、战争迷雾）；技能层（three.js 3D 渲染、物理碰撞、多输入适配）；工具层（键盘 / 鼠标 / 触屏 / 陀螺仪，纯本地离线）。

> 倾斜棋盘让小球在真实物理世界里滚向终点：14 个关卡 × 7 种主题，机制逐关引入，后期考验空间智力与探索。

**交付工作区**：`D:/Projects/3D迷宫`（交付成果放此；过时版本移入其 `archive/`。全局映射见 [[wiki/meta/code-repos]]）

**交付物**：

- [x] 关卡 1-8：平面迷宫逐关引入机制（深渊洞、洞阵等）
- [x] 关卡 9-11：Perplexus 式多层立方迷宫（默认只见当前层，需 X 光透视、全景镜头、战争迷雾雷达探索）
- [x] 关卡 12-14：巨型地图（25 格宽巨构平面、17×17×3 三层巨塔）
- [x] 多端输入：键盘 / 鼠标 / 触屏虚拟摇杆 / 陀螺仪（iOS 需 https/localhost）
- [x] 纯离线：所有库与纹理本地化，双击 `index.html` 即玩（另附 `启动游戏.bat`）
- [ ] 全部完成后：`status: completed` → 移入 `wiki/archives/`

## 项目关键点
**核心内容**：从「平面倾斜迷宫」到「多层立方 + 巨构地图」的完整难度曲线——后期迷宫默认隐藏结构，把「看见」本身变成玩法资源。

**关键难点**：

- 多层立方的可视化：只能看当前层时如何不让玩家迷失——X 光透视 / 全景 / 雷达三种辅助手段的取舍。
- 巨型地图性能：25 格宽平面与 17×17×3 巨塔在浏览器内的渲染与碰撞开销。
- 陀螺仪在移动端的权限与兼容（iOS 强制 https/localhost）。
