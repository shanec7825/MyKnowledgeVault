# Relational Databases

**项目**：关系数据库入门学习——以 PostgreSQL 为主线，从 SQL 基础到高级特性。

## 目标

- 掌握关系数据库核心概念：表结构、约束、事务（ACID）、索引、视图
- 以 PostgreSQL 为实践平台，系统学习 SQL 和数据建模
- 后续扩展：MySQL 对比、数据库设计范式、查询优化、ORM 使用
