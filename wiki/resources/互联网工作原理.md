# 互联网工作原理

本文基于 cs.fyi 的《[[wiki/resources/How does the Internet Work|How does the Internet Work]]》（2023-02）梳理互联网的基础原理，作为后端入门的第一块基石：网络与协议、数据包与路由、IP/TCP、DNS、HTTP/HTTPS、SSL/TLS、端口与 socket。

## 概述

> **总纲**：互联网是**网络的网络（network of networks）**——家庭、办公室等本地小网络彼此连接，组成全球互联的互联网。

- 互联网的前身起源于 1960 年代末美国国防部的 ARPA 网络，最初目标是建设去中心化、抗毁的通信网络（"能抵御核打击"是常见的历史简化叙述，实际历史更复杂）。
- 现代互联网依赖一组**标准化协议**交换信息，确保数据可靠、安全地传输。

## 工作原理概览

- 数据在互联网上被拆分为**小数据包（packet）**，从你的设备发送到路由器。
- 路由器检查数据包并**逐跳转发**，直到到达最终目的地。
- 两大核心协议：
  - **IP（Internet Protocol）**——负责把数据包路由到正确的目的地（寻址与路由）。
  - **TCP（Transmission Control Protocol）**——保证数据包可靠、按序传输（可靠传输）。
- 上层还有 DNS、HTTP、SSL/TLS 等协议协同工作。

## 基础术语

| 术语 | 含义 |
| --- | --- |
| Packet（数据包） | 在互联网上传输的小单位数据 |
| Router（路由器） | 在不同网络之间转发数据包的设备 |
| IP Address（IP 地址） | 网络设备的唯一标识，用于把数据路由到正确目的地 |
| Domain Name（域名） | 人类可读的名称，如 google.com |
| DNS | 域名系统，把域名翻译成 IP 地址 |
| HTTP | 在客户端（浏览器）与服务器（网站）之间传输数据 |
| HTTPS | HTTP 的加密版本，提供客户端与服务器之间的安全通信 |
| SSL/TLS | 提供互联网安全通信的协议族 |

## 协议的角色

- 协议 = 一组规则与标准，规定设备之间如何交换信息。
- 常用协议：IP（路由）、TCP/UDP（可靠/高效传输）、DNS（域名翻译）、HTTP（客户端-服务器数据交换）。
- 标准化的关键价值：**不同厂商、不同系统的设备可以无缝互通**——例如 A 公司的浏览器可以访问 B 公司的服务器，只要双方都遵循 HTTP。

## IP 地址与域名

- IP 地址是设备的唯一标识，常见形式为四段数字，如 `192.168.1.1`（IPv4）。
- 域名由两个或更多部分构成、以点分隔，如 `google.com`。
- 解析流程：输入域名 → 计算机向 DNS 服务器发送 DNS 查询 → 返回对应 IP 地址 → 用该 IP 连接目标资源。

## HTTP 与 HTTPS

- **HTTP**：浏览器发送 HTTP 请求给服务器，服务器返回 HTTP 响应（含请求的数据）。
- **HTTPS**：用 SSL/TLS 加密客户端与服务器之间传输的数据，保护登录凭据、支付信息等敏感数据；浏览器地址栏显示锁形图标与 `https` 前缀。

## 用 TCP/IP 构建应用

- **Port（端口）**：标识设备上运行的应用/服务；每个应用/服务分配唯一端口号。
- **Socket**：IP 地址 + 端口号的组合，代表一个具体的通信端点；连接建立在两个 socket 之间。
- **Connection（连接）**：建立连接时双方协商参数（最大段大小、窗口大小等）。
- **Data transfer**：数据以**段（segment）**传输，每段带序号与元数据，保证可靠交付。
- 常用配套协议：HTTP、FTP（文件传输）、SMTP（邮件传输）。

## SSL/TLS 安全通信

- **证书（Certificate）**：SSL/TLS 证书包含服务器身份信息，由受信任的第三方（证书颁发机构 CA）签名，用于建立信任。
- **握手（Handshake）**：客户端与服务器交换信息，协商加密算法与连接参数。
- **加密（Encryption）**：连接建立后，数据按协商的算法加密传输。
- 实践要点：传输敏感数据时使用 SSL/TLS、维护有效证书、按最佳实践配置连接。

## 新兴趋势（来源观点）

文章列举的互联网演进方向：5G（更快速度、更低延迟、更大容量）、物联网 IoT、人工智能（机器学习 / 自然语言处理）、区块链、边缘计算。这些属于面向未来的趋势性观点，阅读时注意时效性。

## 总结

- 互联网 = 全球互联的计算机网络，用标准协议族交换数据。
- 核心机制：路由器转发数据包，IP 路由 + TCP 可靠传输。
- 必备术语：packet、router、IP 地址、域名、DNS、HTTP、HTTPS、SSL/TLS。
