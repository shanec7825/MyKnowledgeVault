# Learn Python in Y Minutes

- **来源**：[https://learnxinyminutes.com/zh-cn/python/](https://learnxinyminutes.com/zh-cn/python/)
- **权威性**：community（Learn X in Y Minutes 社区项目，Louie Dinh 原著，多位贡献者维护）
- **摄入文件**：`inbox/Learn Python in Y Minutes.md`
- **摄入日期**：2026-08-03

Learn Python in Y Minutes（Y 分钟速成 Python）是一份面向程序员的 **Python 3** 速查式教程，用大量可直接运行的代码示例覆盖：原始数据类型与运算符、变量与集合（列表/元组/字典/集合）、流程控制与迭代器、函数、模块、类与继承（含多重继承）、以及生成器与装饰器等高级用法。页面底部附完整脚本下载：`learnpython.py`。

注意：教程基于 Python 3；旧版 Python 2 有单独的教程页。文中说明字典在 Python 3.7 之前无序、3.7 起按插入顺序排列。
