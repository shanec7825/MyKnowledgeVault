# 机器学习

本文基于 IBM Think 的《[[wiki/resources/What is Machine Learning|What is Machine Learning]]》（Dave Bergmann）梳理机器学习的定义、与 AI 的关系、工作原理、三大类型与深度学习架构，作为 [[What is ML and its types]] 项目的第一步。

## 概述

> **总纲**：机器学习（Machine Learning, ML）是**人工智能（AI）的子集**，聚焦于能够从训练数据中"学习"模式、并据此对新数据做出准确*推断*的算法。这种模式识别能力让 ML 模型无需显式硬编码指令即可做出决策或预测。

- 训练只是手段，**泛化**才是根本目标：把训练集上的强表现转化为真实场景中的有用结果。
- ML 已成为 AI 的主流：预测、自动驾驶、大语言模型与生成式 AI 都以它为骨干。
- 术语溯源："machine learning"一词常追溯至 Arthur L. Samuel 1959 年发表于 IBM Journal 的论文（用跳棋游戏演示机器自学超过编写者）。

## 机器学习 vs 人工智能

- 简记：**所有 ML 都是 AI，但不是所有 AI 都是 ML**。
- 非 ML 的 AI：if-then 规则系统（如恒温器）、专家系统决策树——逻辑由人显式编程，任务变复杂后规则模型越来越脆弱。
- ML 的逻辑**从数据中隐式习得**：以垃圾邮件过滤为例，只需选对算法 + 足够样本，模型在训练中自行学会判别。

## 工作原理

- **数值化**：数据点的特征必须表达为数值（向量），每个维度对应一个特征的数值。
- **特征工程**：特征选择 + 特征提取把原始数据精炼为 ML 可用形式；深度学习能自动化大部分特征工程（更可扩展、但可解释性更低）。
- **参数优化**：以房价线性回归为例，Price = A×面积 + B×房间数 − C×房龄 + Base；A/B/C 是模型参数，训练即寻找令输出最准确的参数（损失最小化）。

## 三大类型

| 范式 | 数据与目标 | 典型任务 | 代表算法 |
|------|-----------|---------|---------|
| [[wiki/resources/What is Machine Learning|监督学习]] | 标注数据 + 外部 ground truth；最小化损失函数 | 分类、回归 | 线性回归、SVM、朴素贝叶斯、逻辑回归、决策树 |
| [[wiki/resources/What is Machine Learning|无监督学习]] | 无标注数据；发现内在模式 | 聚类、关联、降维 | K-means、GMM、DBSCAN、PCA、autoencoder、t-SNE |
| [[wiki/resources/What is Machine Learning|强化学习]] | 状态-动作-奖励元组；最大化奖励 | 机器人、游戏、推理模型 | PPO、Q-learning、actor-critic |

- **监督学习**：对照 ground truth（通常来自标注数据）调整参数，直到输出与标签一致；数学目标 = 最小化损失函数输出。
  - **自监督学习**：监督信号来自无标注数据本身（autoencoder 重建误差、LLM 掩码词预测）——LLM 的主要预训练方法。
  - **半监督学习**：标注 + 未标注数据并用。
- **无监督学习**：无 ground truth、无常规损失函数；聚类（K-means、GMM、DBSCAN）、关联（电商推荐）、降维（PCA、LDA、t-SNE、autoencoder）。
- **强化学习**：智能体（agent）通过试错学习；组件 = 状态空间、动作空间、奖励信号、策略 π(s)→a；基于策略（PPO）直接学策略，基于价值（Q-learning）学状态价值，actor-critic 混合。
- 实际训练常**混合**多种范式：LLM 先经监督式预训练 + 微调，再用 RLHF 等强化技术继续微调；集成学习聚合多算法输出。

## 深度学习

- 多层人工神经网络（"深"），2000 年代末至 2010 年代初借助 GPU 与大数据成为主流；每个"神经元"执行非线性激活函数，权重与偏置为待优化参数。
- **反向传播** + **梯度下降**：计算每个节点对损失的贡献，可优化数十亿权重；代价是需要海量数据与算力。
- **通用逼近器**：理论上任何函数都存在能复现它的网络结构。
- 四大架构：
  - **CNN**：卷积层用滤波器提取特征 → 计算机视觉主力。
  - **RNN**：隐状态记忆处理序列 → 早期序列任务主力。
  - **Transformer（2017）**：注意力机制选择性聚焦关键信息 → LLM 与生成式 AI 的基石。
  - **Mamba（2023）**：状态空间模型变体，Transformer 的竞争架构（尤其 LLM）。

## 应用领域

- **计算机视觉**：图像分类、目标检测、图像分割、OCR；医疗诊断、人脸识别、自动驾驶。
- **NLP**：聊天机器人、语音识别、机器翻译、情感分析、文本生成、摘要、AI agents。
- **时间序列**：异常检测、市场分析、预测。
- **图像生成**：扩散模型、VAE、GAN。

## MLOps 与工具链

- **MLOps**：构建 → 部署 → 维护的流水线实践；数据策管、模型选择、训练后验证（防过拟合）、监控模型漂移、模型治理。
- **常用库**：PyTorch、TensorFlow、Keras、Hugging Face Transformers（深度学习）；Pandas、Scikit-learn、XGBoost、NumPy（传统 ML）——多基于 Python。
