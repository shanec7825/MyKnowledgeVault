## 方法论沉淀

- 「完整可运行」类交付的验收方式 = **测试断言 + 基准实测数字**，不要只交源码。
- 本轮先写 Python 复算期望值（growCount=14、moveCount=131064、头插 49995000、缩容 1024→512），
  **再**编译 C++。好处是避免「编译通过但断言值写错」这种最难查的失败。
- MSYS2 免安装部署路径：`mirrors.tuna.tsinghua.edu.cn/msys2/distrib/msys2-x86_64-latest.tar.xz`
  → Python `tarfile.open(...,'r:xz')` 解压 → 改 mirrorlist → `pacman-key --init && pacman-key --populate msys2`
  → `pacman -Sy --noconfirm --needed mingw-w64-x86_64-gcc`。全程不需要 GUI 安装器。
