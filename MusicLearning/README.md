# 音乐基础入门

目标不是一开始学乐器或啃乐理，而是先建立一套“听得懂、说得出”的音乐坐标系。

## 一张图记住音乐的几个核心维度

- **节拍 Beat**：稳定的时间脉搏，像走路时规律的脚步。
- **节奏 Rhythm**：声音具体落在哪些时刻，是“长短、疏密、重音”的排列。
- **拍号 Meter**：把连续节拍分组，例如 4/4 是“强-弱-次强-弱”。
- **速度 Tempo**：节拍有多快，常用 BPM 表示。
- **音高 Pitch**：声音“高还是低”，主要对应基频；高一个八度时频率约翻倍。
- **音色 Timbre**：同一个音高、同样响度，钢琴和小提琴仍然听起来不同的原因。
- **响度 Dynamics**：声音强弱以及强弱随时间的变化。
- **旋律 Melody**：音高随时间形成的一条“线”。
- **和声 Harmony**：多个音高同时或连续组织形成的关系。

## 最重要的三个区分

### 1. 节拍 ≠ 节奏
节拍是背景中的等间隔网格，节奏是声音选择在哪些格子上出现。

### 2. 音高 ≠ 响度
音高主要是频率的感觉；响度主要是振幅/能量的感觉。高音不一定更响。

### 3. 音色 ≠ 音高
A4 无论由正弦波、钢琴还是吉他发出，都可以保持同一音高，但波形与泛音结构不同，所以音色不同。

## 建议学习顺序

1. 先学 **节拍 → 节奏 → 拍号 → BPM**，能跟拍。
2. 再学 **音高 → 八度 → 音程 → 音阶**，能听出“上行/下行”和大致跨度。
3. 再学 **音色 → 泛音 → 包络**，理解为什么不同乐器“声音质地”不同。
4. 最后把它们合起来看 **旋律、和声、曲式**。

## 交互图

打开同目录下的 **[music_basics.html](./music_basics.html)**。\n\n如果你想专门把“节拍/节奏”听出区别，打开 **[beat_lab.html](./beat_lab.html)**：可交互比较 2/4、3/4、4/4、6/8、5/4，以及 Straight、Swing、反拍和切分。

其中最值得先玩的部分是 **环形音序器（Circular Sequencer）**：

- 一整圈 = 一个小节的时间；
- 圆周角度 = 在这个小节中的时间位置；
- 不同半径的圆环 = 不同音高；
- 旋转指针扫到圆点时就触发对应音符；
- 你可以点击圆周格点添加/删除音符，直接“看见节奏和旋律”。

这个表示法特别适合建立“音乐其实是声音事件在时间上的结构”这一感觉。
