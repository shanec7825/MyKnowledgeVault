# inbox — 源文档收件箱

> 源文档（原文 / 剪藏）只进不改不删；消化后**用自己的话**写成 `wiki/resources/concept/<主题>.md`，并挂回相关 project 页。规则见 [[CLAUDE.md]]。

## 子文件夹（分类用，不必执着）

| 文件夹 | 收什么 | 现有内容示例 |
| --- | --- | --- |
| `后端与网络/` | 网络 / HTTP / DNS / 浏览器 / API / 数据库 / Node 等后端线来源 | MDN《HTTP 概述》、DNS、PostgreSQL Tutorial、JSON:API、Caching Proxy 想法 |
| `编程语言/` | 语言语法与教程类来源（Python / JS / MDN 章节） | Learn Python in Y Minutes、MDN《JavaScript 指南》中文各章 |
| `人工智能/` | ML / DL / AI 综述类来源 | What is Machine Learning（IBM） |
| `英语精读/` | 精读材料及其译文的 inbox 原件 | How to Do Great Work 双语译文 |

## 流向

- 新到的 raw 文件：按主题丢进上面四个文件夹之一；拿不准就放 inbox 根目录，下次整理再归。
- 英文精读例外：消化后原文迁 `wiki/resources/resource/`、生词迁 `wiki/resources/words/`；inbox 原件保留。
- 其余来源消化后留在原位，不建来源页副本。
