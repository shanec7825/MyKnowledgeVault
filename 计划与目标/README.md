# 目标与阶段管理

## 怎么使用
1. 自由选择一门学科，只看当前阶段的**范围、产出、通过标准**；阶段可持续任意时间。
2. 熟悉的部分直接验收，不必重学；不熟悉的部分按需要阅读、实验、练习。
3. 自己能独立完成时填写一个证据链接，修改 YAML 的 `stage_status: verified`；再自行决定是否前往下一阶段。
4. `track_mode: main` 是候选主线（默认计算机系统和数学竞赛），`light` 是轻量方向（默认英语），`reference` 只是备用资料；都可以任意更改。
5. 不规定每日截止时间、每周复盘或学习时长，不用把所有课程都变成同一天的待办事项。

## 旧文件的处理
- `01-课程目标` 已替换为详细阶段目标。
- `02-学习任务` 仍保留先前内容和日期，但**所有日期是过往建议，不再进入总览/提醒**；可把任务作为阶段验收题库。
- `03-每日计划`、`04-每周复盘`、原模板仅供历史参考，完全可以不打开。
- 其它原始课程与实验文件不会搬动。

## 证据与不确定性
教材和 HTML 存在 ≠ 自己学会；与 AI 讨论过 ≠ 经过独立验收。当前阶段 1 只是从资料推测的诊断入口。无法直接读取 ChatGPT 左侧全部 Projects 内容，因此保留待验证状态。
