## 按课程统计任务
```dataview
TABLE length(rows) AS "任务总数",
  length(filter(rows, (r) => r.status = "done" AND r.verified = true)) AS "已验收",
  length(filter(rows, (r) => r.status = "doing")) AS "跟进中",
  length(filter(rows, (r) => r.status = "todo")) AS "待开始"
FROM "计划与目标/02-学习任务"
WHERE type = "learning-task"
GROUP BY course
SORT course ASC
```

## 到期复习 / 诊断
```dataview
TABLE course AS "课程", review_kind AS "复习类型", review_due AS "到期日", mastery AS "掌握等级"
FROM "计划与目标/02-学习任务"
WHERE type = "learning-task" AND review_due AND review_due <= date(today)
SORT review_due ASC
```

## 近期计划任务
```dataview
TABLE course AS "课程", scheduled AS "计划日", status AS "任务状态"
FROM "计划与目标/02-学习任务"
WHERE type = "learning-task" AND scheduled AND status != "done"
SORT scheduled ASC
```

## 未验收任务
